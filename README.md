## Professional projects & impact

### ⚡ Energy Data Analytics Platform — Avantsec

Contributed to a platform designed to make public data from Brazil's national electric power system easier to explore and analyze for the energy investment sector.

- Worked with **85 datasets, 162,000+ files, and approximately 101 GB of data**.
- Helped turn fragmented datasets into information accessible through analytical dashboards.
- **Stack:** Python · React · PostgreSQL · Redis

### 📄 AI-Powered Federal Gazette Search — Brintell

Contributed to a platform using **Retrieval-Augmented Generation (RAG)** to explore and analyze publications from Brazil's Federal Official Gazette.

- Built for exploring a collection covering **15+ years of official publications**.
- Combined web development, document retrieval, and LLM-powered interactions.
- **Stack:** Node.js · React · MongoDB · LLMs / RAG

### 💬 AI-Powered Customer Communication — Brintell

Contributed to an automated customer communication platform for internet service providers, integrating language models into business workflows.

- Worked on web functionality and integration with the **OpenAI API**.
- **Stack:** Node.js · HTML · CSS · OpenAI API
